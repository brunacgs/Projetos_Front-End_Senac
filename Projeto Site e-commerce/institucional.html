Missão, Visão e Valores

Missão

Desafiar a lógica do consumo e a utilidade do cotidiano. Existimos para transformar tarefas simples em experiências complexas, garantindo que a sofisticação seja sempre acompanhada de um leve sentimento de "por que eu comprei isso?".

Visão

Tornar-nos a marca líder mundial em produtos que ninguém precisa, mas que todos desejam exibir. Queremos um mundo onde a estética seja tão dominante que a funcionalidade se torne um conceito meramente opcional e, preferencialmente, esquecido.

Valores

Ineficiência de Alto Padrão

Se funciona de primeira, não é Contra-Senso.

Estética Autoritária

O design não se adapta ao usuário; o usuário é quem deve lutar para se adaptar ao design.

Transparência Irônica

Somos honestos sobre a inutilidade de nossos produtos.

Luxo Absurdo

A elegância reside no esforço desnecessário.

Política de Trocas e Devoluções

Trocas

Aceitamos trocas apenas se o produto, por algum erro de fabricação, acabar funcionando perfeitamente. Isso fere nossa identidade visual.

Devoluções

O cliente tem 7 dias para se arrepender, mas o processo de devolução exige que você monte um quebra-cabeça de 5.000 peças (totalmente branco) para liberar a etiqueta de postagem. Acreditamos que a persistência é a base do nosso relacionamento.

Política de Envios

Prazo

Nossos envios são feitos via "Logística Existencial". O produto chegará quando o universo decidir que você está pronto para o desafio.

Embalagem

Todos os itens são enviados em caixas dentro de caixas, dentro de mais caixas, todas seladas com fita adesiva de alta resistência, para que a experiência de desembalar seja o seu primeiro exercício de paciência do dia.

Rastreamento

O código de rastreio enviado fornecerá apenas a localização filosófica do produto (ex: "Em algum lugar entre a intenção e o destino").

Política de Privacidade

Sua privacidade é tão importante para nós quanto a utilidade de nossa colher com furo. Coletamos seus dados apenas para saber para quem enviar nossos catálogos passivo-agressivos. Prometemos não vender suas informações para terceiros, a menos que eles ofereçam um design de site mais bonito que o nosso.

Política de Dados

Nós rastreamos seus movimentos em nosso site para entender quanto tempo você leva para perceber que a "alça interna" da caneca é real. Esses dados são usados para alimentar nosso algoritmo de "Nível de Paciência do Cliente", que define quem recebe nossas edições limitadas mais frustrantes.

® Contra-Senso Design

Nossos produtos são peças de arte utilitária feitas para quem valoriza o debate acima do conforto.
